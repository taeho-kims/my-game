# Game Brief: 슬라임 노다지

**One-sentence pitch:** 영웅을 하늘에서 떨어뜨려 슬라임을 쓸고, 커서로 전리품을 쓸어 담아 상자를 터뜨린 뒤, 그 골드로 영웅단을 키워 다시 출격하는 짧은 런형 수집 게임.

## Core loop
- 클릭한 자리에 영웅(기사·궁수·광전사)을 강하시킨다. 착지 충격을 주고, 이후는 자동으로 슬라임을 처치한다.
- 커서 자석으로 떨어진 코인을 상자에 쓸어 담는다. 많이 모을수록 상자 등급이 오른다(나무→구리→은→금→수정).
- 제한 시간(기본 24초)이 끝나면 상자가 열린다. 획득 골드는 모은 양 × 등급 배율이다.
- 골드로 스킬 트리(16노드)를 올리고 재출격한다. 슬라임은 판마다 `1.07^판 수`만큼 강해진다.

## Player goal & fail state — what "working" looks like
- 목표: 한 판 안에 더 높은 상자 등급을 채워 골드를 최대화하고, 트리를 키워 최고 기록을 갱신한다.
- 실패: 하드 실패는 없다. 시간이 끝나면 항상 개봉하고, 못 채우면 낮은 등급·낮은 배율을 받는다. "작동함" = 한 판이 개봉·정산으로 끝나고, 골드가 트리 업그레이드에 반영되어 저장된다.

## MVP — what must exist to be the game
- 영웅 강하 + 착지 충격 + 기사 자동전투 (손맛의 핵심)
- 슬라임 스폰/이동과 코인 드롭, 판마다 스케일 `1.07^판 수`
- 커서 자석 코인 수집 + 상자 5등급과 배율 (프로토타입 `TIERS` 값 그대로)
- 시간제 한 판 + 상자 개봉 연출과 정산 화면
- 스킬 트리 16노드 + 골드 소비 + 저장 (프로토타입 `NODES` 값 그대로, 데이터 파일로 분리)
- 궁수·광전사 영웅 타입 + 숫자키 1·2·3 선택 (핫바)
- 트리가 해금하는 이벤트 4종: 황금 슬라임, 슬라임 비, 보물 고블린, 대왕 푸딩

## Out of scope — not building this
- 수치 재밸런싱, 신규 영웅·노드·콘텐츠 (포팅 단계에서는 프로토타입 값 유지)
- 모바일·터치 지원, 멀티플레이, 클라우드 세이브, 다국어
- 배경음악 (프로토타입의 합성 효과음 수준만)
- **MVP 이후 확장 후보:** 상자 등급·배율을 중심에 둔 런 구조 (판마다 상자 도박/선택 요소)

## Build order
1. 강하 + 착지 충격 + 기사 자동전투 + 커서 자석 수집: 손맛부터 검증
2. 상자 등급·배율 + 시간제 한 판 + 개봉 정산
3. 스킬 트리 + 저장 + 판마다 스케일
4. 궁수·광전사 + 핫바
5. 이벤트 4종

---
**Who it's for / what they feel:** 짧은 판을 반복하며 영웅단을 키우는 증분·방치형 팬. 떨어뜨리고 쓸어 담을 때의 묵직하고 쫀득한 타격감이 최우선 품질 목표.

**Art & audio direction:** 8×8 도트 스프라이트를 2배로 키운 픽셀아트(640×360 정수 배율, 프로토타입의 공간 값은 1280×720 기준이라 0.5배로 옮김), 초록 들판과 목재 UI, 8비트 스퀘어/트라이앵글 효과음.

**Reference game:** When Chests Rain Tons of Loot (LeenGameDev, Steam): 강하→수집→상자 폭발→스킬 트리 루프의 원본. 이 루프 구조만 참고하고, 이름·아트·콘텐츠·수치는 이 프로젝트의 것(슬라임 노다지 프로토타입)을 쓴다. 2순위 참고: Vampire Survivors의 자동 전투와 판 끝 성장.
